# دانلودر ماز و Sales Center 24

افزونهٔ شخصی Chrome، نسخهٔ **۰٫۴٫۱**، برای ذخیرهٔ ویدیوهای قابل پخش در حساب کاربر به فایل MP4. افزونه شامل انتخاب کیفیت، نام فایل و محل ذخیره، نمایش فایل در پوشه، پنل شناور، صف دانلود و زمان‌بندی شبانه است.

## ساختار پروژه

```text
extension/       کد قابل نصب افزونه و مجوز کتابخانهٔ mux.js
scripts/         بررسی کد، ساخت ZIP و تعمیر مدت فایل‌های قدیمی
tests/           آزمون‌های صف و زمان‌بندی MP4
local/work/      تمام فایل‌ها و آزمون‌های قبلی، fixtureها و ابزارهای محلی
local/outputs/   ویدیوهای خروجی، تصاویر آزمون و بسته‌های نسخه‌های قبلی
dist/            ZIP ساخته‌شده برای نصب
```

`local/` و `dist/` در Git ثبت نمی‌شوند. آرشیو محلی شامل فایل‌های حجیم و خصوصی مرورگر/شبکه است؛ این پوشه برای نگهداری سابقهٔ کامل روی همین دستگاه منتقل شده و برای انتشار در GitHub نیست. یک clone تازه از GitHub کد افزونه و ابزارهای پروژه را خواهد داشت، ولی ویدیوها، نشست مرورگر و fixtureهای خصوصی همراه آن نیستند.

## نصب در Chrome

1. `chrome://extensions` را باز و Developer mode را فعال کن.
2. Load unpacked را بزن و پوشهٔ `extension` همین پروژه را انتخاب کن.
3. صفحهٔ درس را تازه‌سازی و ویدیو را یک‌بار پخش کن؛ پنل دانلود کیفیت‌ها را نمایش می‌دهد.

**نصب فعلی روی همین دستگاه:** مسیر قدیمی افزونه با junction ویندوز به `extension/` متصل مانده است. فایل‌ها واقعاً به درایو D منتقل شده‌اند و ویرایش این پوشه روی همان نصب اعمال می‌شود. برای این جابه‌جایی نیازی به حذف یا نصب دوبارهٔ افزونه نیست. پس از تغییر کد، وقتی دانلودی فعال نیست، Reload افزونه و سپس تازه‌سازی صفحه کافی است. حذف و نصب افزونه از یک مسیر تازه ممکن است شناسه و تنظیمات محلی آن را عوض کند.

راهنمای کامل کاربر: [README.fa.html](extension/README.fa.html).

## توسعه و بررسی

Node.js 20 یا جدیدتر برای ابزارهای توسعه کافی است؛ افزونه در Chrome بدون نصب Node کار می‌کند. وابستگی npm برای بررسی و آزمون پایه لازم نیست.

```powershell
cd "D:\my projects\biomaze-salescenter-downloader"
npm run check
npm test
npm run test:media
npm run package
```

`test:media` از fixture خصوصی موجود در `local/work/extension-fixture` استفاده می‌کند. می‌توان پوشهٔ fixture را با متغیر `BIOMAZE_FIXTURE_DIR` مشخص کرد. این آزمون در clone تازه بدون تهیهٔ fixture اجرا نمی‌شود. `package` در Windows با PowerShell یک ZIP در `dist/` می‌سازد. آزمون‌های کامل Playwright قبلی نیز در آرشیو محلی نگهداری شده‌اند؛ آن‌ها سابقهٔ آزمون این دستگاه هستند و برای محیط دیگر نیازمند تنظیم مسیر runtime و fixture خواهند بود.

## تعمیر مدت فایل‌های قدیمی

نسخهٔ ۰٫۴٫۱ مدت واقعی را در سربرگ MP4 ثبت می‌کند. برای فایل‌های ساخته‌شده با نسخه‌های قدیمی، ابزار تعمیر یک **فایل جداگانه** می‌سازد و یکسان‌ماندن داده‌های صدا و تصویر را با SHA-256 بررسی می‌کند:

```powershell
node scripts/repair-mp4-duration.cjs "C:\path\original.mp4" "C:\path\fixed.mp4"
```

این ابزار برای خروجی fragmented MP4 همین افزونه است و مبدل عمومی فرمت ویدیو نیست. نام مقصد باید تازه باشد؛ فایل اصلی بازنویسی نمی‌شود.

## معماری و محدودیت‌ها

- `sites.js`: سایت‌ها، نشانی درس و دامنهٔ پلیر مجاز.
- `page.js`: ارتباط با نمونهٔ HLS پلیر سایت و دریافت قطعه‌ها با loader همان پلیر.
- `writer.js` و `mp4-timing.js`: تبدیل MPEG-TS به MP4 با mux.js و ثبت مدت نهایی، بدون فشرده‌سازی دوباره.
- `panel.js` و `save.js`: پنل، فایل موقت روی دیسک و تحویل فایل کامل به Chrome Downloads.
- `background.js` و `queue-*`: مالکیت دانلودها، صف پایدار، زمان‌بندی و مدیریت تب دانلود.

ورود به سایت از طریق نشست موجود Chrome انجام می‌شود؛ ورود خودکار و ذخیرهٔ رمز عبور پیاده‌سازی نشده است. برای دانلود شبانه، مرورگر و تب مخصوص صف باید باز بمانند. بستن تب یا مرورگر موجب شروع دوبارهٔ ویدیوی نیمه‌تمام از ابتدا می‌شود. پشتیبانی فعلی برای VOD دارای MPEG-TS، H.264/AAC و AES-128 یا بدون رمزگذاری است؛ پخش زنده، صدای جداگانه و fMP4 ورودی پشتیبانی نمی‌شوند.

## ارسال به GitHub

مخزن محلی روی شاخهٔ `main` آماده شده است. برای انتشار، یک مخزن خالی در حساب خودت بساز، نشانی آن را جایگزین کن و اجرا کن:

```powershell
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

هیچ remote یا مخزن آنلاین به‌صورت خودکار ساخته نشده است. برای تغییرات بعدی از `git status`، `git add` و `git commit` استفاده کن.
